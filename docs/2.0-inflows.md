# Candidate flow, concentration and mass inflows

`easysewer.model.Model` provides independent `inflows` and `dwf` relation
collections. Each key combines the node ID and constituent. FLOW uses the
dedicated `FLOW` enum marker, not a pollutant name. Both collections apply to
junctions, storage nodes, dividers and outfalls.

```python
from datetime import timedelta
from easysewer.model import Model, Ref
from easysewer.model.network import Junction
from easysewer.model.resources import InlineTimeSeries, SeriesPoint, Pattern
from easysewer.model.inflows import FlowInflow, DryWeatherFlow

model = Model()
model.nodes.add(Junction(id="J", elevation=0))
model.timeseries.add(InlineTimeSeries(id="Hydrograph", points=(
    SeriesPoint(time=timedelta(), value=0.1),
    SeriesPoint(time=timedelta(hours=1), value=0.3),
)))
model.patterns.add(Pattern(id="Monthly", kind="MONTHLY", factors=(1, 1.2)))
model.inflows.add(FlowInflow(
    node=Ref(collection="swmm:nodes", key="J"),
    series=Ref(collection="swmm:timeseries", key="Hydrograph"),
    scale_factor=0.5, baseline=0.2,
    pattern=Ref(collection="swmm:patterns", key="Monthly"),
))
model.dwf.add(DryWeatherFlow(
    node=Ref(collection="swmm:nodes", key="J"), baseline=0.1,
    patterns=(Ref(collection="swmm:patterns", key="Monthly"),),
))
model.nodes.rename("J", "Upstream")
model.inflows.update(("Upstream", "FLOW"), baseline=0.25)
model.convert_units("CMS")
text = model.to_document().text
```

The example starts in default CFS units and demonstrates editing/export. A
runnable drainage network also needs its links and analysis period.

## Parameters and behavior

`FlowInflow` has optional `series`, `scale_factor`, `baseline` and `pattern`.
Omitted scale and baseline resolve to 1 and 0. Its flow is
`series_value * scale_factor + baseline * pattern_factor`. Scaling does not
multiply the baseline. Series interpolation is linear with zero outside its
record range. The baseline accepts any of the four pattern kinds; a WEEKEND
pattern has factor 1 on weekdays. A missing series is written as an empty quoted
token (`""`); `*` is a literal series reference, not an absence marker.

The INP FLOW type and mass-conversion slots are ignored by the fixed native
engine. They are not modeled as active parameters. Original tokens remain in
untouched source, with a diagnostic for nonstandard values; regenerated rows use
`FLOW 1` when these interior slots are needed to reach later parameters. Omitted
interior scale/baseline values are likewise materialized only when required.

`DryWeatherFlow` has a required `baseline` and up to four ordered `patterns`
slots, each a pattern reference or `None` for an empty quoted slot. The engine
selects the final pattern of each kind, regardless of supplied order. MONTHLY
and DAILY factors multiply the baseline; HOURLY supplies the hour factor unless
a WEEKEND pattern replaces it on Saturday/Sunday. Same-kind patterns do not
multiply each other, and their repetition produces a diagnostic. The model
retains the original order and every reference, including overwritten slots.

Negative series values, scale factors, baselines and pattern factors remain
valid; the engine can use them as withdrawals. External and DWF components add
independently at the node. Negative external flow is counted as outflow by the
engine, while negative DWF is included in its DWF balance category. This layer
does not clip values or reinterpret those native accounting rules.

## References, units and source

Node/resource renames propagate through both relation types. Node renames also
rekey their collection entries, with collision rollback. Deleting a referenced
node, series or pattern fails unless explicit cascading is requested. FLOW and
pollutant references have different key representations; extension variants can
share a node without overwriting its FLOW entry.

FLOW series consumers declare the `flow` dimension. Shared flow sequences convert
once, as do each relation's flow baselines. Scaling and pattern factors remain
dimensionless. Sharing a sequence with incompatible temperature, rainfall or
stage dimensions is rejected. `FileTimeSeries` paths retain origin and rebase on
save; converting their numeric values requires an explicit external-data
operation and cannot be achieved by changing the model's flow unit.

Untouched source retains optional tokens, comments and repeated sections. The
final assignment to a node/constituent takes effect; editing that entry or
normalizing collapses repeated assignments and retains comments. If any row in
the relation group is malformed, the whole group stays source-owned with an
error rather than exposing a valid prefix as an independent editable relation.

Run validation also inspects the actual projected source. An earlier overridden
assignment with a missing series/pattern still fails native parsing. An earlier
inflow assignment to an active rainfall series leaves a native non-rainfall
usage flag, even if the final assignment no longer refers to it. These cases
require explicit normalization of obsolete assignments or corrected references;
the ordinary lossless writer does not silently repair them.

## Validation and limits

Tests compare 64 combinations of four node kinds, two unit systems and eight
optional FLOW forms against independent hand-authored inputs. Rebuilt models
match full lateral-flow, node-depth, link-flow, mass-balance and OUT histories.
Further native checks cover all 24 DWF pattern orders, final same-kind selection,
empty slots, monthly boundaries, weekday/weekend rules, each baseline pattern
kind, negative values, series interpolation/range, external-file relocation,
repeated assignments and source-level error repair. Five conversions from CFS
cover all six flow units, checking double-precision trajectories and OUT values
with float32 tolerances.

`ConcentrationInflow`, `MassInflow` and `DryWeatherConcentration` now own
pollutant rows alongside FLOW. Their `constituent` is a pollutant Ref, and their
key is `(node_id, "POLLUTANT:" + pollutant_id)`. CONCEN is the default pollutant
external type. It needs external FLOW at the same non-outfall node; DWF flow
does not supply this external carrier. Outfalls can use reverse-flow quality.
CONCEN ignores the input mass-factor slot; MASS requires a positive factor
converting both the raw series and baseline to mg/s, µg/s or counts/s.
Scaling still applies only to the series. Pollutant concentrations and MASS
raw values/factors do not change when hydraulic units change. See
[quality units](2.0-quality.md) for explicit MG/L ↔ UG/L conversion.

Undefined constituent names starting with the full FLOW keyword are native aliases for FLOW; a defined pollutant such as FLOWER remains a pollutant. The exact FLOW ID is reserved. Noncanonical prefixes and ignored trailing input columns have diagnostics.
