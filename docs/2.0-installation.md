# Installation

Python 3.10 or later is required. Run the following commands from the repository root using the built local package:

```console
python -m pip install dist/2.0.0/native/easysewer-2.0.0-py3-none-any.whl
python examples/v2_first_run.py runs/first-example
```

The native package includes Windows/Linux libraries. Backend probing determines actual availability:

```python
from easysewer.runtime import StandardBackend
print(StandardBackend().probe())
```

For modeling, conversion and result reading only, install the wheel with the same name under `dist/2.0.0/pure/`. Install one package variant per environment. The pure package provides neither a native solver nor a WebAssembly solver; success on host Python does not establish browser support. See the [pure Python build guide](2.0-pure-python.md).

The core runtime has no third-party Python dependencies. Quick Start plotting requires Plotly, and interactive notebook execution also requires Notebook/Jupyter; these are example dependencies. Rebuilding packages requires setuptools and wheel. See [testing and builds](2.0-testing.md).
