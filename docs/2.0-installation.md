# Installation

Python 3.10 or later is required. Install the published 2.0 release from PyPI:

```console
python -m pip install easysewer==2.0.0
python -c "from easysewer import Model; print(Model())"
```

Version `2.0.0` is a final release. A fresh `pip install easysewer` selects the latest compatible final release. To upgrade an existing installation, use `python -m pip install --upgrade easysewer`. The 2.0 API does not support 1.x callers.

## Install a local build

Before publication, install the built wheel instead. From the repository root:

```console
python -m pip install dist/2.0.0/native/easysewer-2.0.0-py3-none-any.whl
python examples/v2_first_run.py runs/first-example
```

## Check the simulation backend

The PyPI distribution and local native package include Windows/Linux libraries. Simulation requires compatible native libraries; the wheel's `any` tag does not promise native execution on every operating system or architecture. Backend probing determines actual availability:

```python
from easysewer.runtime import StandardBackend
print(StandardBackend().probe())
```

For a local package without native libraries, install the wheel with the same name under `dist/2.0.0/pure/`. This is a separate local build, not a second PyPI variant. Install one package variant per environment. The pure package provides neither a native solver nor a WebAssembly solver; success on host Python does not establish browser support. See the [pure Python build guide](2.0-pure-python.md).

The core runtime has no third-party Python dependencies. Quick Start plotting requires Plotly, and interactive notebook execution also requires Notebook/Jupyter; these are example dependencies. Rebuilding packages requires setuptools 77.0.3 or later and wheel. See [testing, builds and publishing](2.0-testing.md).
