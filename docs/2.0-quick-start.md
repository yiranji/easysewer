# Quick Start

The [Quick Start notebook](../cases/Case_1%20Quick%20Start/main.ipynb) uses the 2.0 API to read the cubic network, edit rainfall, run a simulation, and query and plot results by object ID. Install the current package and Plotly before running it in a notebook environment.

Native execution requires an available Windows/Linux backend. Pure Python supports the modeling and existing-archive reading portions, but cannot start native calculations. The standalone verification entry point is `tools/qualify_quick_start.py`; use `--help` for its arguments.

To start with an empty model, use the [first runnable example](2.0-first-run.md). The [editable-network example](../examples/v2_edit_model.py) demonstrates reference updates and transaction rollback. See the [model guide](2.0-model.md) for the API. Use a new output directory for every run to avoid overwriting saved results.
