# 2.0 architecture

| Layer | Responsibility |
| --- | --- |
| INP document | Original byte preservation, lexical diagnostics and revision-bound text patches |
| Schema/feature | Explicit registration, dependency ordering, record ownership and unknown-content preservation |
| Model | Immutable records, reference graphs, editing transactions, INP/JSON projection and validation |
| Runtime | Resource capture, isolated native processes, execution status, checkpoints and artifact publication |
| Results | ID-based queries, units and provenance, OUT/RPT reading and portable archives |

The public entry point is `easysewer.Model`. Model imports do not load native libraries. See the [model](2.0-model.md), [Runner](2.0-runner.md) and [result](2.0-output.md) guides for specific contracts.

## Extension maintenance scope

The A–H trials cover cross-sections/OUTLETS, multiple pollutants and composite keys, LID layers/deployments, groundwater and treatment expressions, seasonal RDII, events and map metadata, promotion of unknown content, and result-table extensions. Maintenance must consider creation/editing, references and units, JSON/INP round-trips, native execution and archives together. Original trial counts and package digests belong to [historical records](development-archive.md) and do not replace current tests.

## Document operations

```python
from easysewer.io.inp import InpDocument

document = InpDocument.read("network.inp")
assert document.to_bytes() == open("network.inp", "rb").read()

# Repeated [CONDUITS] occurrences are all visible, in source order.
for row in document.records("conduits"):
    print(row.number, row.values)

# This is a lexical edit, not a Model operation or a reference-aware rename.
row = document.records("CONDUITS")[0]
edited = document.replace_token(row.number, 3, "120.5")
edited.report.raise_for_errors()  # lexical validity only
edited.write("copy.inp")
```

`read` strictly decodes UTF-8, recognizing a UTF-8 BOM. Supply `encoding=` for
other encodings. `to_bytes()` preserves an unmodified file byte-for-byte.
`write()` encodes before touching the destination, writes a temporary file in
the destination directory, and replaces the destination only after writing
succeeds. It creates missing parent directories. It does **not** rebase external
paths: document copying and semantic Model export are different operations.

Line and column numbers are one-based. Text edit offsets are zero-based
character offsets in `document.text`, with exclusive ends; they are not byte
offsets. `replace_token` takes a one-based line and a zero-based token index.
The document remains unchanged after edits. Apply a `DocumentPatch` only to the
revision from which it was created; stale, overlapping and ambiguous insertions
are rejected before any changes occur.

The lexer follows SWMM's double-quote and literal-backslash rules. In the
[v5.2.4 input lexer](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/input.c),
the first semicolon starts a comment even inside a quoted token. Consequently
`format_token` rejects semicolons and embedded quotes instead of emitting a path
that the engine would truncate. TITLE remains free text. Malformed records stay
in the document with diagnostics; preserving an invalid input does not validate
it or make it runnable.

## Feature registration and ownership

A decoder returns a typed value, the one-based source lines it has consumed,
and diagnostics. It can consume a whole block or combine several sections; it
is not restricted to one object per line. Claims refer only to data records,
not headers, blank lines or comments.

```python
from dataclasses import dataclass
from easysewer.schema import DecodedFeature, FeatureDescriptor, SchemaRegistry

@dataclass(frozen=True)
class Title:
    lines: tuple[str, ...]

class TitleDecoder:
    def decode(self, document, profile):
        rows = document.records("TITLE")
        return DecodedFeature(
            value=Title(tuple(row.content for row in rows)),
            claimed_lines=frozenset(row.number for row in rows),
        )

registry = SchemaRegistry()
registry.register(
    FeatureDescriptor(key="example:title", sections=frozenset({"TITLE"})),
    TitleDecoder(),
)
decoded = registry.decode(document)
print(decoded.features["example:title"].value)
print(decoded.opaque_records)
```

Registration is explicit and local to a registry. Duplicate feature keys,
missing dependencies, dependency cycles, out-of-scope claims, and competing
claims fail rather than silently overwriting source ownership. Unknown rows
remain unclaimed and available in the original document.

Different feature variants can share a section if they own different rows.
For example, implementing FLOW inflows must not consume pollutant rows until
the pollutant variant is implemented. `support_for(line_number)` reports the
owning descriptor's level, or `PRESERVED` for an unclaimed row. A registered
descriptor's level is a declaration by its implementation, not automatic proof
that simulation has been verified. The network feature and semantic
writers are described in [2.0-model.md](2.0-model.md).

`DecodedDocument` is a snapshot: its provenance maps are read-only and adding a
decoder to the registry cannot alter an earlier snapshot. Decode again to
explicitly promote previously opaque records; the source document remains the
single retained copy. Decoder implementations should return immutable domain
values; the registry does not deep-freeze arbitrary extension objects.

Unsupported profile/dependency combinations retain their source and produce a diagnostic. See [analysis options](2.0-options.md) for profile defaults.

## Cooperative in-memory document work

`InpDocument.from_bytes(..., checkpoint=...)`, `from_text(..., checkpoint=...)`
and `document.apply(patch, checkpoint=...)` accept an optional no-argument
callback. Built-in line/token scans and patch traversal check between batches;
long unquoted token scanning also checks internally. Nested operations inherit
an active work scope. Callback failures preserve their original exception object
and chain, including `ValueError`, `OSError` and `KeyboardInterrupt`, without
turning the request into a parse diagnostic. No partial document is returned,
and the unchanged source document and revision-bound patch can be reused.

The callback must not mutate its inputs. A single decoding, encoding, regex,
allocation, sorting, joining or system operation cannot be forcibly interrupted.
The file-oriented `read`/`write` signatures and atomic publication behavior are
unchanged; this callback API does not introduce a cancellation after publication.
