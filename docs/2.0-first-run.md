# From an empty model to portable results

The [complete script](../examples/v2_first_run.py) uses the public 2.0 API to create two nodes, a circular conduit and an inflow series, edit the conduit length, round-trip INP/JSON, run a native simulation, query depth and save an archive. It requires Python 3.10 or later.

The current version is `2.0.1`. Run this in an environment with the current package installed:

```console
python examples/v2_first_run.py runs/first-example
```

Use a new output directory for every run; the script does not overwrite previous results. Native execution requires the Windows/Linux package containing the solver libraries.

## Model and units

The script imports the 2.0 `Model` from top-level `easysewer`; it is the same type as `easysewer.model.Model`.

The model uses CMS flow units, meters for length and depth, and cubic meters per second for inflow. Inflow starts at zero, peaks at 0.020 at minute 3 and returns to zero at minute 10. Simulation continues to minute 20 to include recession. The routing step is one second and the reporting step is one minute.

Conduit inlet and outlet offsets are explicitly zero. These required INP columns are also written as zero when omitted, but an explicit zero after rereading is not the same field value as the model's omitted `None`.

Records are changed through collection `update` methods. `validate(for_run=True)` checks run constraints and `raise_for_errors()` stops on errors. After reading the INP and JSON back, the example checks node, conduit, inflow and time-series values directly, rather than using text similarity as a substitute.

## Output

- `network.inp`, `network.json`: the model before execution.
- `run/`: INP, RPT, OUT and assets published by Runner.
- `archive-moved/`: the complete result archive, moved after saving and then reread.
- `summary.json`: maximum saved depth, time, units, flow continuity error and OUT digest.

This example produces 20 depth samples and two node-depth summary rows. The three tested environments reported a maximum saved depth of approximately 0.062993 m and flow continuity error of approximately 0.000001%. The code reads actual results; it does not substitute these reference values.

`maximum_saved_depth` is the maximum of saved one-minute samples. RPT maxima computed at internal routing steps have different sampling semantics. Times come directly from OUT and may include milliseconds in this example; they are not forced to whole minutes. For other models, inspect diagnostics and continuity errors as well as run status.

## Pure Python usage

With the pure Python package, create and validate a model without starting a solver:

```console
python examples/v2_first_run.py runs/model-only --build-only
```

After copying the entire `archive-moved` directory elsewhere, read it in a pure Python environment:

```console
python examples/v2_first_run.py copied-results/archive-moved --read-archive
```

Loading an archive checks its file contents. Reading existing results does not rerun the model. Historical input and run paths are provenance records; their original locations need not still exist.

## Validation and limits

Windows Python 3.10/3.13 and Linux Python 3.12 each exercised three paths: a complete native run, pure Python modeling and pure Python reading of moved native results. Complete OUT bytes matched across those environments. Recovery checks moved the original run directory and prohibited reading either its old location or its new location, while also prohibiting ctypes imports and subprocess creation.
