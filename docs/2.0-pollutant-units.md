# Pollutant-unit conversion extensions

The candidate `Model.convert_pollutant_units(id, units)` uses feature-owned
conversion rules. It supports MG/L ↔ UG/L independently of the hydraulic flow
unit. The standard quality and inflow features register their own rules; the
coordinator does not import or enumerate those domain classes.

`reinterpret_pollutant_units(id, units)` explicitly changes only the label,
including `#/L`. Count/mass conversion requires physical information that the
model does not infer. Ordinary record edits cannot change pollutant units.

## Registering a consumer

Types in `easysewer.model.pollutant_units` define the protocol:

| Type | Purpose |
| --- | --- |
| `PollutantUnitTransform(value_type, convert)` | Exact record type and trusted conversion callback |
| `PollutantConversionContext` | Owner/target Refs, source/target unit labels, factor, profile and snapshot lookups |
| `PollutantUnitConversion(value, resources=())` | Replacement record and optional shared resource proposals |
| `PollutantResourceConversion(target, path, value)` | One reference path's consent to a proposed resource replacement |

All constructors use keyword arguments. A feature codec declares a tuple in
`pollutant_unit_transforms`. `ModelSchema.register()` checks types, duplicate
registrations within the tuple, and conflicts across features. Only rules active
for the current SWMM profile apply. Model copies carry the registry snapshot.
Do not mutate registered codec implementations; extension handlers are trusted
Python code, as with other codec and scenario hooks.

For a new immutable record containing `pollutant: Ref` and `threshold: float`:

```python
from dataclasses import replace
from easysewer.model.pollutant_units import (
    PollutantUnitTransform, PollutantUnitConversion,
)

def convert_sensor(row, context):
    if row.pollutant.canonical == context.target.canonical:
        row = replace(row, threshold=row.threshold * context.factor)
    return PollutantUnitConversion(value=row)

# Add this declaration to the feature codec that owns QualitySensor records.
pollutant_unit_transforms = (
    PollutantUnitTransform(value_type=QualitySensor, convert=convert_sensor),
)
```

Callbacks run once for each registered record, including potential indirect
consumers. Unaffected records return their original value. All callbacks see the
same original immutable values through `context.record(ref)` and the same
reference graph through `context.referenced_by(ref)`; they cannot observe another
callback's pending numeric updates. `context.factor` is 1000 or .001. There is no
mutable store in the context.

Every direct consumer of the target pollutant must have an exact-type rule.
Subclass inheritance does not silently confer conversion support. A rule that
owns nested formula variants must handle each supported variant explicitly and
reject others. Pollutant dependencies must use actual Refs, not hidden ID
strings. Return `PollutantUnitConversion` even for a deliberately unchanged
consumer, such as a surface mass loading expressed in project lb/kg units.

The replacement must preserve the exact record type, identity, referenced
identities and their multiplicities. Reference paths may move within an expression
when a conversion wraps a variable in unit factors. Field validation and feature constraints still apply.
The protocol changes numeric meaning and unit labels; graph edits are separate
explicit operations. These callback plans are runtime Python values, not new
Model JSON wire types and never executable instructions loaded from a payload.

## Shared resource agreement

A CONCEN inflow proposes replacing its inline time series using the original
series multiplied by the factor. It also returns its converted baseline. Every
consumer referencing that time series must supply the same proposed value for
its own exact reference path. Multiple consenting consumers or two paths on the
same record still produce one resource replacement.

An extension can participate without modifying either the inflow feature or the
coordinator. For example, its callback can include:

```python
from easysewer.model.pollutant_units import PollutantResourceConversion

series = context.record(row.series)
converted = replace(series, points=tuple(
    replace(point, value=point.value * context.factor) for point in series.points
))
proposal = PollutantResourceConversion(
    target=row.series, path=("series",), value=converted,
)
return PollutantUnitConversion(value=converted_sensor, resources=(proposal,))
```

Proposal paths address the original snapshot and include tuple indexes where
applicable. Missing/incorrect paths, duplicate
proposals, conflicting values and uncovered consumers reject the operation. A
direct transform on the resource record must also agree with consumer proposals.
The standard CONCEN handler refuses external files; materialize or explicitly
convert them first. A MASS consumer keeps its raw data and converts its mass
factor, so it cannot consent to a CONCEN rewrite of the same series. Existing
dimension validation may reject incompatible sharing before callbacks run.

Opaque content blocks conversion because its dependencies are unknown. Callback
failure, resource disagreement, native file dependency guards or final validation
failure roll back all changes. This transaction protects Model state; it does not
sandbox arbitrary Python side effects inside an extension callback. Extension
callbacks must be pure and must not change external files.

## Scenarios and verification

`ChangePollutantUnits(target=Ref(...), units="UG/L", mode="convert")` is the ninth
standard scenario operation, with wire tag `scenario:pollutant_units`. Its target
must be a scalar Ref in `swmm:pollutants`; `mode="reinterpret"` changes only the
label. JSON omits no semantics when the default `convert` is omitted. An optional
`required_capabilities=("scenario:pollutant_units",)` explicitly requires support.
Older registries preserve an unrecognized operation and cannot execute it.

Scenarios return independent model copies and record all actual changes,
including shared series. A later failure returns no partial result and leaves the
original Model unchanged. An earlier rename can be followed by a conversion
targeting the new ID. As with hydraulic conversion, the Model must be valid when
conversion begins; it cannot consume a temporarily unresolved forward reference.

Tests exercise independently registered consumers through INP/JSON/scenarios,
shared resource agreement and conflicts, exact type registration, invalid plans,
original snapshot visibility and rollback. Native comparisons cover three active
washoff formulas under US/SI, both concentration conversion directions in one
scenario, shared CONCEN data, MASS/DWF values and label-only reinterpretation.
Expected models are independent literal INPs. [TREATMENT](2.0-treatment.md) now
registers its own formula input/output transformations and native tests through
this protocol. [LID](2.0-lid.md) registers removal percentages with the same protocol; they remain dimensionless.
